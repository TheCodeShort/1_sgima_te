# Reglas de trazabilidad SIGMA-TE

## Objetivo
Garantizar que cada requisito, historia de usuario, caso de uso y criterio de aceptación pueda rastrearse dentro del sistema.

## Reglas
- Todo requisito debe poder vincularse con al menos una historia de usuario.
- Toda historia de usuario debe poder vincularse con un caso de uso o comportamiento observable.
- Todo criterio de aceptación debe validar una historia específica.
- Ninguna funcionalidad crítica debe quedar sin trazabilidad.
- No debe existir una regla o historia sin contexto funcional claro.

## Flujo de trazabilidad
Requisito -> Historia de usuario -> Caso de uso -> Criterio de aceptación -> Prueba

## Criterios de calidad
- La trazabilidad debe ser legible.
- La trazabilidad debe ser consistente.
- La trazabilidad no debe contradicir el dominio.
- La trazabilidad no debe incluir funciones fuera del alcance.

## Uso
Este archivo se usa para revisar que la documentación del proyecto no esté suelta ni desordenada.
