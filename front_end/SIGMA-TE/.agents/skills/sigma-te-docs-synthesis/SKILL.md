# SIGMA-TE Docs Synthesis

## Propósito
Esta skill sirve para convertir todo el material de SIGMA-TE en texto final claro, coherente y bien organizado.

## Cuándo usarla
- Cuando se necesite un informe.
- Cuando se deba unificar lo ya escrito.
- Cuando haya que hacer una síntesis final del proyecto.
- Cuando se quiera convertir documentación técnica en texto académico o de portafolio.
- Cuando se requiera una versión más limpia y presentable.

## Guardrails
⚠️ No agregar funcionalidades nuevas.
⚠️ No cambiar decisiones técnicas.
⚠️ No reescribir el proyecto desde cero.
⚠️ No inventar conclusiones.
⚠️ No mezclar resumen con expansión innecesaria.

## Principio central
SI el contenido ya existe,
ENTONCES se organiza.
SI el contenido está disperso,
ENTONCES se sintetiza.
SI el texto pierde contexto,
ENTONCES se corrige.

## Flujo de trabajo
-> Leer el material fuente.
-> Identificar ideas repetidas.
-> Ordenar por progresión lógica.
-> Eliminar redundancias.
-> Mantener el contexto SIGMA-TE.
-> Preservar decisiones importantes.
-> Dejar un texto fluido y entendible.

## Qué debe conservar
- Alcance del proyecto.
- Justificación técnica.
- Decisiones de arquitectura.
- Roles del sistema.
- Reglas de negocio.
- Trazabilidad.
- Enfoque offline-first.

## Qué debe evitar
- Repetición innecesaria.
- Redacción inflada.
- Conceptos que no pertenecen al proyecto.
- Conclusiones inventadas.
- Títulos vacíos o genéricos.

## Checklist interno
- [ ] Conservé el sentido original.
- [ ] Eliminé repeticiones.
- [ ] Ordené el contenido.
- [ ] Mantuve SIGMA-TE como contexto central.
- [ ] No agregué funciones nuevas.
- [ ] Dejé el texto listo para entregar.

## Estilo de respuesta
- Claro.
- Formal sin exagerar.
- Fluido.
- Útil para informe o portafolio.
