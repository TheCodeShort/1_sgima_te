# Reglas de interfaz SIGMA-TE

## Objetivo
Mantener la experiencia de usuario simple, clara y útil.

## Reglas
- Cada pantalla debe tener una sola intención principal.
- Los formularios deben ser cortos y entendibles.
- Los mensajes de error deben ser claros.
- El usuario debe saber si algo quedó pendiente.
- La interfaz no debe depender de explicaciones externas.
- La navegación debe evitar pasos innecesarios.

## Estados visuales importantes
- Cargando
- Guardado
- Pendiente de sincronización
- Error
- Sin conexión
- Disponible

## Criterio
La interfaz debe reducir fricción, no aumentar carga mental.
