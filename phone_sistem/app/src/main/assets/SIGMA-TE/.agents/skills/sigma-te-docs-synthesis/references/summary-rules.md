# Reglas de síntesis SIGMA-TE

## Objetivo
Reducir contenido sin perder esencia.

## Reglas
- Conservar la idea principal.
- Quitar repeticiones.
- Ordenar la información.
- Mantener el contexto SIGMA-TE.
- No inventar conclusiones nuevas.
- No cambiar decisiones técnicas.

## Flujo
- Leer
- Seleccionar lo esencial
- Ordenar
- Unificar
- Revisar coherencia
