# Plantilla BDD SIGMA-TE

## Estructura
Dado que [contexto],
cuando [acción],
entonces [resultado].

## Reglas
- Un escenario debe validar una sola intención principal.
- El contexto debe ser realista.
- La acción debe ser concreta.
- El resultado debe ser observable.

## Ejemplo
Dado que el técnico inició sesión,
cuando registra una falla en un equipo,
entonces el sistema guarda el reporte y deja trazabilidad.
