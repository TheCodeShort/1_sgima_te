# Estructura sugerida de informe SIGMA-TE

## Secciones base
- Introducción
- Contexto del proyecto
- Problema identificado
- Propuesta de solución
- Arquitectura general
- Roles y alcance
- Reglas de negocio
- Trazabilidad
- Consideraciones técnicas
- Conclusiones

## Regla
El informe debe presentar el proyecto de forma coherente, sin repetir ideas ni mezclar temas.
