# Mapa de pantallas SIGMA-TE

## Propósito
Definir la estructura visual mínima del sistema web/PWA sin entrar en reglas de negocio profundas.

## Pantallas base
- Inicio / panel principal
- Login
- Lista de equipos
- Detalle de equipo
- Registro de falla
- Registro de mantenimiento
- Carga de evidencia
- Historial del equipo
- Gestión de usuarios
- Gestión de roles
- Estado de sincronización

## Reglas de navegación
- La navegación debe ser simple.
- El usuario debe entender dónde está.
- Cada pantalla debe resolver una tarea real.
- Las pantallas críticas deben tener acceso rápido.
- El sistema debe mostrar estado de conexión cuando aplique.

## Observación
Este mapa no define la lógica final de negocio, solo la estructura de experiencia.
