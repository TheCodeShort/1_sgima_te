# Casos de prueba SIGMA-TE

## Tipos de casos
- Caso exitoso
- Caso de validación
- Caso de error
- Caso por rol
- Caso por estado
- Caso por sincronización

## Estructura recomendada
- ID
- Objetivo
- Precondición
- Pasos
- Resultado esperado
- Evidencia

## Regla
Cada caso debe relacionarse con una historia de usuario o una regla de negocio.
